# 🕷️ Karan Reju — Spider-Man Themed Portfolio

> **"With great code comes great scalability."**  
> An interactive, comic-book-inspired portfolio showcasing the engineering missions, tech arsenal, and projects of **Karan Reju** — Full-Stack & AI Engineer based in Kochi, Kerala [Earth-616].

---

## ✦ Live Highlights & Innovative Features

- **🌆 Three.js 3D Rooftop Skyline & Silhouette Hero:**
  - Real-time WebGL city skyline with window lighting and ink edge outlines.
  - Crouched silhouette Spider-Man on a skyscraper corner.
  - Scroll-driven 3D web strand extruded in real-time with Catmull-Rom spline physics.
  - Raycasted 3D web-projectile shooting toward cursor clicks.
- **🕸️ Spider-Verse Suit Mode Switcher:**
  - **Classic 616:** Vintage comic book halftone paper with classic red and deep blue.
  - **Miles Morales:** Cyberpunk neon bio-electric cyan and yellow theme.
  - **Symbiote Venom:** Pitch-black suit with purple glow and alien aesthetics.
- **🔊 Web Audio API Sound Synthesizer:**
  - In-browser synthesized 8-bit comic sound effects for web shooting (`THWIP!`) and punch impacts (`KAPOW!`).
  - Includes a quick Mute / Unmute audio toggle in the navigation bar.
- **⚠️ Spidey-Sense Cursor:**
  - Animated comic danger squiggles vibrating around the cursor when hovering over interactive elements.
- **🤖 Suit AI (Karen HUD):**
  - Rotating developer quip telemetry bar (*"Web shooters calibrated at 420 PSI"*, *"Chai fuel levels at maximum capacity in Kochi"*).
- **📰 The Daily Bugle Exclusive:**
  - Vintage newspaper clipping of J. Jonah Jameson demanding an investigation into how Karan automated delivery routes and deployed Go backends before his afternoon cigar.
- **💥 Comic Explosions & 2D Web Splatters:**
  - Dynamic SVG comic bursts (`THWIP!`, `DEBUGGED!`, `KAPOW!`, `DEPLOY!`, `404 SOLVED!`) on click.

## ✦ How to Run Locally

Simply clone and open `index.html` in your browser:

```bash
git clone https://github.com/karanrejuuu/spiderman-port.git
cd spiderman-port
open index.html
```

Or deploy instantly via **GitHub Pages** (Settings → Pages → Source: `main` branch).
